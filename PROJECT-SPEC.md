## Runtime contract shared by workers
Version 1.2.0. Vanilla JS/HTML/CSS, MV3 static content scripts. No background. Files at root. site-rules.js classic IIFE exposes globalThis.SiteRules and module.exports when Node; UI uses external classic scripts with site-rules.js first. API normalizeSite(input) returns hostname or null; normalizeRules(array) returns normalized deduplicated strings; findMatchingRule(hostname,rules) returns matching rule or null (prefer exact then most-specific parent); matchesDisabledSite(hostname,rules) boolean. Matching exact or dot-boundary subdomain; IP literals exact only. Keep www, lowercase/trim, URL parser, http/https URLs and bare host:port; reject malformed hosts, credentials, wildcard, non-http schemes. Support localhost, IPv4, bracketed IPv6 and IDN cleanly. Reject ambiguous numeric forms if practical.
Storage {settingsVersion:1, disabledSites:[]}, chrome.storage.sync. UI reads latest state before writes, serializes own operations, catches errors inline, listens onChanged. No global transactional guarantees claimed for simultaneous editors on separate devices.
Content cache initialized before enabling navigation, onChanged updates immediately; stale initial get must not overwrite newer changes. Failed settings load is fail-closed. Key guards: key Backspace, not defaultPrevented/composing/repeat/Ctrl/Alt/Meta; Shift forward. Capture window.addEventListener; composedPath checks input (all types), textarea, inherited contenteditable, designMode and closed-shadow/custom editor uncertainty conservatively. No website-specific editor hacks. Disabled event untouched. Preserve frames with simplest safe behavior: use top hostname when accessible, ancestorOrigins for cross-origin if available, fail closed if top identity unknown; navigate only current frame history (no cross-frame double delivery). Document frame limitations.
Popup activeTab + storage only, displays hostname/status; exact exclusion removable unless another parent still covers; inherited rule identifies parent and directs to options rather than removing parent. Protected chrome pages and both modern/legacy Web Store origins unsupported. No tabs/history/scripting permissions. Existing static matches may narrow to http/https for clear support.
Options add/remove, normalize, duplicates and validation inline. textContent only for untrusted input. No alerts or unsafe HTML.
